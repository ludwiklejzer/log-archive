# log-archive

[roadmap.sh](https://roadmap.sh/projects/log-archive-tool) project

## Overview

This program compresses the specified log directory into a .tar.gz archive.

## Requirements

- Node.js
- npm

## Installation & Usage

1. Install the program globally using npm

```bash
npm install -g git+https://github.com/ludwiklejzer/log-archive.git
```

2. Make sure npm global packages are in your PATH and run `log-archive`

```bash
log-archive /path/to/log_directory
```

## Uninstallation

```bash
npm uninstall -g log-archive
```
